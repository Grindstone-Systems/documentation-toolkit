# Agent assets

- `skills/documentation-toolkit/SKILL.md` — the rules for completing a pack, as a skill. Copy the folder into your assistant's skills directory (for Claude Code: `~/.claude/skills/` or a project's `.claude/skills/`). Every workspace also carries the same rules in `AGENTS.md`, so the skill is optional.
- Client setup for the MCP server is in [../docs/LOCAL.md](../docs/LOCAL.md).
